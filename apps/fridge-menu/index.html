Fridge Menu

Effective date: 2026-08-29

Fridge Menu (냉장고 메뉴) is a local-first Android app. Ingredient lists, favorites, and recent menus are stored only on the user's device.

Current App Boundary

  • Zero Android permissions
  • No network permission
  • No account, analytics, tracking, advertising SDK, or external API
  • No server upload or developer-side server copy of local app data

Important Limits

Fridge Menu provides flexible meal directions. They are not recipes, nutrition advice, allergy guidance, or food-safety information. Check ingredients and use your own judgment when cooking.
