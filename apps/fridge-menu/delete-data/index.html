Fridge Menu

Delete Data

Effective date: 2026-08-29

Fridge Menu (냉장고 메뉴) stores ingredient lists, favorites, and recent menus only on the user's device. It has no account and maintains no developer-side server copy of this local data.

1. Clear Ingredients In The App

Use the in-app “목록 비우기” action to remove the ingredient list. This action removes ingredients only; it does not remove favorites or recent-menu history.

2. Clear App Storage

Use the Android operating system's app-storage controls to clear Fridge Menu storage. This removes locally stored ingredients, favorites, and history.

3. Uninstall The App

Uninstall Fridge Menu to remove the app and its locally stored ingredients, favorites, and history according to the device operating system's behavior.

No Server Copy

LABONDANCE Co., Ltd. does not receive this local app data and has no server copy to access, retain, or delete. A remote deletion request cannot delete data that exists only on the user's device.

Contact

For privacy or deletion questions, contact support@nuvopilot.com. Do not include passwords, payment information, or other sensitive information.
